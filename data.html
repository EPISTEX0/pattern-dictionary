Data display

Patterns for presenting large amounts of information: tables, filterable lists, and content that collapses until needed. Every demo works with mouse, touch and keyboard.

Data table

A table of records with sorting, filtering and multi-row selection. The header row sticks to the top while the table scrolls. On narrow screens, each row becomes a card and the column headers become a strip of sort buttons. Select a column header to sort (select it again to reverse), type in the filter to narrow the list, and select several rows to show the bulk actions bar.

Project members

Use whenusers need to compare many records on the same attributes, find a specific row, or act on several rows at once (export, delete, change permissions): admin consoles, order lists, member directories.

Avoid wheneach record has only 1–2 attributes or the content is mostly images: use a list or a card grid. On phones, tables with more than 4 columns should become stacked cards.

Accordion

A list of sections that expand and collapse. Each section shows only its heading; the content opens below it when selected. In one-at-a-time mode, opening a section closes the previous one. The demo uses the native <details> element, so Ctrl+F still finds text inside closed sections. Select a heading, or Tab to it and press Enter or Space.

Does the app work offline?
Yes. Recently opened notes are stored on your device, and edits made offline sync automatically when you reconnect.
Where is my data backed up?
We create a backup every hour and keep it for 30 days. You can restore any note to any version from that period.
Will I lose my notes if I cancel Pro?
No. Your account returns to the Free plan and all notes remain. Only Pro features (extended version history, large files) are locked.
How many devices can I use?
Free plan: 2 devices. Pro plan: unlimited. You can remove old devices in Settings → Devices.
How do I invite someone to edit?
Open the note, select Share and enter an email address. Invitees get View or Edit access, which you can change at any time.

Carousel / Slider

A horizontal strip of content that slides. It shows one item at a time, with part of the next item visible to signal there is more. It does not autoplay by default; when Autoplay is on, it pauses while the pointer or focus is inside. Swipe, use ‹ › or the dots, or Tab into the frame and use the ← → keys.

Timeline / Activity feed

A chronological list of activity. Each entry states who did what, to which object, and when; the newest entry is on top, grouped by day and joined by a vertical line. Filter by activity type, or select + New activity to add an event to the top of the list.

Comparison table

A table that compares products criterion by criterion. Each column is an option and each row an attribute, with rows grouped by topic. Product names stick to the top and criteria stick to the left while scrolling. Turn on Show differences only to hide identical rows; hover or tap a cell to highlight its column.

Filter chips / Faceted search

Filtering across several attributes, with results that update instantly. The left column holds facets (attribute groups) such as topic and level; each option shows how many results remain if selected. The chip row at the top holds quick on/off filters. Each active filter appears as a chip with × to remove it. Select a facet or chip to filter.
