How it works

From impression to instruction

Recognizing a well-made interface is the first step. Describing it requires the name of each part.

01

Notice

Scrolling through a page, you can tell it is well made but cannot point to what makes it so. The impression is there; the vocabulary is not.

02

Name

The dictionary breaks an interface into named parts: a pill-shaped navigation bar that floats over the page is a Floating nav, a grid of unequal tiles is a Bento grid, a frosted-glass surface is Glassmorphism.

03

Prompt

With the names in hand, describing a design to an AI tool means combining keywords. The result matches the request far more closely than “make it look better”.
