UX components

Interface components that help people act and decide faster: navigation bars, action buttons, pricing tables, and command palettes. Every demo on this page works with a mouse, keyboard, or touch.

Floating / shrinking nav

Navigation bar that shrinks into a pill. At the top of the page, the navigation bar spans the full width. Once the user starts scrolling, the bar detaches from the edges, shrinks into a rounded pill, and floats over the content on a blurred background (backdrop blur). Scroll inside the frame.

Use whena landing page is long, people need navigation at every scroll position, and the imagery and hero need generous space. A pill takes up less room than a full-width bar.

Avoid whenthe app has many menus or needs a full toolbar: a pill is too narrow and forces important items into hiding.

Sticky CTA

Sticky call-to-action bar. When the main “Add to cart” button leaves the screen, a small bar slides up from the bottom edge with the product name, the price, and the same action. The bar hides again when the main button returns to view. Scroll inside the frame, then press “Add to cart”.

Swipe to compare plans

Use whenthe product has 2–4 clearly defined plans and you need to steer people toward one of them, usually the middle plan (decoy effect).

Avoid whenthe price depends on many options (use a price calculator), or there is only one plan: a three-column table then looks empty and unconvincing.

Feature tabs

Features grouped behind tabs. Instead of giving each feature its own long section, the features share one frame: a tab list on one side and an illustration on the other that changes with the selected tab. On narrow screens, the tabs form a horizontal row above the illustration. Click or tap each tab; when a tab has focus, use the arrow keys to switch.

Command palette

Search-driven access to commands. A search box that floats in the middle of the screen, opened with a keyboard shortcut or a button; typing a few characters filters the commands and pages. On desktop, click the frame, press ⌘K / Ctrl+K, then use ↑ ↓ and Enter to choose. On a phone, tap the search field in the frame. Type “dark” to find Switch to dark theme.

Avoid whenthe page is a marketing site or the product targets new users: the ⌘K shortcut is invisible, so a command palette cannot replace a visible menu. On mobile, always provide a button that opens it.

Empty state

What a screen shows before it has data. When there is no data yet, the interface shows a small illustration, one sentence of explanation, and one primary action to get started, instead of leaving the content area blank. Press “Create first task” or “Use template”, then press “Clear all” to return to the empty state.
